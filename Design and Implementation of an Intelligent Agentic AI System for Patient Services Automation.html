// Pedagogy Objectives

Learning Outcomes

By completing this curriculum assessment, students will demonstrate academic proficiency to:

  • Explain the theoretical foundations of Generative AI and Agentic AI, distinguishing between reactive, goal-driven, and autonomous agent paradigms.
  • Describe the architectural components of agentic systems, including reasoning engines, memory subsystems, tool interfaces, and orchestration layers.
  • Apply prompt engineering principles to design effective system prompts, structured outputs, and tool-calling instructions for LLM-based agents.
  • Implement agentic workflows using LangChain and LangGraph, constructing stateful graphs with conditional edges, cycles, and checkpointing mechanisms.
  • Design and integrate custom tools and function-calling interfaces, incorporating appropriate input validation and error-handling strategies.
  • Construct Retrieval-Augmented Generation (RAG) pipelines by applying embedding models, vector databases, and chunking strategies to ground agent responses in domain knowledge.
  • Implement memory management strategies — including short-term conversational buffers and long-term vector store-backed memory — to maintain context across agent interactions.
  • Apply established agentic design patterns (ReAct, Reflection, Planning, Tool Use) to architect solutions for real-world problem scenarios.
  • Design multi-agent systems by assigning roles, configuring supervisor–subagent hierarchies, and managing inter-agent communication and delegation.
  • Evaluate agent behaviour using appropriate observability tools, tracing frameworks, and performance metrics including task completion rate, tool accuracy, and cost profiling.
  • Incorporate Human-in-the-Loop mechanisms into agentic pipelines, designing appropriate interrupt nodes, approval workflows, and escalation triggers.
  • Assess the ethical, safety, and security implications of agentic AI deployment, identifying risks such as prompt injection, unintended autonomous action, and data privacy violations.
  • Deploy agent applications as production-ready services, packaging solutions using appropriate API frameworks and environment management practices.
  • Communicate between agents and external services using modern inter-agent protocols (MCP and A2A), evaluating appropriate protocol selection for a given architecture.

// Case Context

Scenario Background

CeylonCare Health Network — Patient Services Automation Agent

CeylonCare Health Network is a mid-sized private healthcare provider operating across Colombo, Kandy, and Galle. The organisation is digitising its patient services department and has commissioned a proof-of-concept Agentic AI system to assist with the following operational tasks: Answering patient queries about services, departments, and doctors using a knowledge base Triaging patient-reported symptoms and routing to the appropriate department Scheduling and managing appointment bookings Summarising patient visit histories for administrative staff Escalating high-risk or ambiguous cases to a human operator Students are hired as AI Engineers at CeylonCare's internal innovation lab. They must design, build, and evaluate a fully functional multi-agent system that automates at least three of the five operational tasks above, with a minimum of two agents collaborating under a supervisor orchestrator.

Academic Domain Focus
Agentic AI Architectures · Autonomous Agent Systems · Human-AI Collaboration · Real-World Automation Applications

Design the initial architecture for the patient services automation agent, incorporating agentic AI principles and autonomous agent systems. Define the system's goals, functionalities, and interaction protocols with human operators.

Core Requirements
  1. Step 1: Define system objectives and key performance indicators
  2. Step 2: Determine the agent's autonomy level and decision-making framework
  3. Step 3: Establish communication protocols for human-AI collaboration
Technical Constraints
  • The system must adhere to CeylonCare Health Network's data privacy and security standards
  • The agent's decision-making process should be transparent and explainable
💡
Socratic Guidance Hint
  • Consider using a modular architecture to facilitate scalability and maintainability
  • Explore the application of machine learning algorithms for predictive analytics and personalized patient services

Task B: Core Application Development for Patient Services Automation
50% of Total Grade

Develop the core application for the patient services automation agent, focusing on the implementation of autonomous agent systems, human-AI collaboration, and real-world automation applications. Integrate the system with CeylonCare Health Network's existing infrastructure and data systems.

Core Requirements

  2. Step 2: Develop the user interface for human operators, ensuring intuitive interaction and minimal training requirements
